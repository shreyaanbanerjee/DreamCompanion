# Engineering Voice & Prose Guidelines

## 1. High-Signal Principles
- **Lead with the solution**: Put the code, the diff, or the direct answer in the first 2 lines.
- **Concrete over abstract**: Use exact file names, line numbers, function signatures, and error codes instead of vague descriptions.
- **Active and confident**: Use strong verbs ("Configured", "Eliminated", "Patched", "Extracted") rather than passive hedging ("It may be observed that...").

## 2. Formatting Discipline
- Use code blocks with syntax highlighting.
- Use clickable file links: `[filename](file:///path/to/file)`.
- Use concise bullet points only when representing parallel, independent items.
- Avoid repeating the user's prompt or stating what is already obvious.

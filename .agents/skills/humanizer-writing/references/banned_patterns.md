# Banned AI Patterns & Slop Catalog

## 1. Cliché AI Vocabulary
Eliminate these tired words and formulaic phrases:
- **"Delve" / "Delving"**: Replace with "explore", "investigate", "examine", or just start the explanation.
- **"Testament"**: ("a testament to...") -> Rephrase with concrete data or evidence.
- **"Tapestry"**: ("a rich tapestry...") -> Delete entirely.
- **"Beacon"**: ("a beacon of...") -> Replace with concrete descriptor.
- **"Orchestrating" / "Symphony"**: Replace with "coordinating", "managing", "executing".
- **"Pivotal" / "Paramount" / "Crucial"**: Often overused; show importance through consequences.
- **"Plethora" / "Myriad"**: Replace with "many", "multiple", or a specific number.
- **"Meticulous" / "Multifaceted"**: Pretentious fluff; cut or specify what was done.
- **"It's important to remember" / "It's worth noting"**: Cut the throat-clearing and state the fact directly.
- **"In conclusion" / "To wrap up"**: Skip closing summaries on short technical answers.

## 2. Structural Anti-Patterns
- **The Sycophantic Opener**: "Certainly! I'd be happy to assist you with that fascinating problem!" -> Ban completely. Start answering in the first sentence.
- **The 10-Item Listicle**: Don't convert a simple 2-step solution into a numbered list of 10 generic platitudes.
- **The False Balance / Unnecessary Disclaimers**: Adding disclaimers to standard programming practices ("Please note that in production, you should consider..."). Be practical and concise.
- **Passive Nominalization**: ("The implementation of the cache was undertaken by...") -> Use active voice ("We implemented the cache...").
